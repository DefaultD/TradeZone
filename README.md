# 🧩 TradeZone

**TradeZone** é uma plataforma de troca de cartas entre usuários, com foco em negociações diretas e sem taxas abusivas.  
Usuários podem publicar suas próprias cartas, negociar trocas e gerenciar coleções com segurança e praticidade.

---

## 🚀 Tecnologias

- **Backend:** Node.js + NestJS + Prisma + PostgreSQL  
- **Frontend:** Next.js (React)  
- **Infra:** Docker + Docker Compose  
- **Estilo:** TailwindCSS  
- **Arquitetura:** Monólito modular (migração futura para microserviços)
